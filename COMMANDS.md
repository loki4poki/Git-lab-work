# Основные команды Git

* **`git init`** — инициализирует новый локальный репозиторий Git в текущей папке.
  * *Пример использования:* `git init`

* **`git clone`** — создает локальную копию удаленного репозитория со всей историей изменений.
  * *Пример использования:* `git clone https://github.com`

* **`git add`** — добавляет изменения из рабочего каталога в индекс (область подготовленных файлов) для следующего коммита.
  * *Пример использования:* `git add README.md` или `git add .` (добавить все файлы)

* **`git commit`** — фиксирует подготовленные изменения в локальном репозитории с поясняющим сообщением.
  * *Пример использования:* `git commit -m "Добавлено описание команд"`

* **`git push`** — отправляет локальные коммиты в удаленный репозиторий (например, на GitHub).
  * *Пример использования:* `git push origin git-commands`

* **`git pull`** — загружает изменения из удаленного репозитория и автоматически сливает их с текущей локальной веткой.
  * *Пример использования:* `git pull origin main`
